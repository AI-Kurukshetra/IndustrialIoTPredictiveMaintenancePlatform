# Skill: Consistent UI

UI must be clean, consistent, and mobile-friendly.

---

# Design Principles

UI must be:

• simple
• consistent
• accessible
• responsive

---

# Component Reuse

Reusable components must be preferred.

Example structure:

components/ui
components/forms
components/dashboard

Avoid duplicated UI code.

---

# UX Requirements

Every feature must include:

• loading state
• empty state
• error state

---

# Mobile Support

UI must work on:

• desktop
• tablet
• mobile

Use responsive layouts.

---

# Navigation

Navigation must be intuitive.

Users should reach major features within 2-3 clicks.

---

# Feedback

User actions must provide feedback.

Examples:

success message  
loading spinner  
error alerts
