# Skill: Code Quality

All generated code must follow these standards.

---

# TypeScript

Rules:

• Strict typing
• Avoid `any`
• Use interfaces or types

---

# Function Design

Functions must be:

• small
• single responsibility
• reusable

---

# File Size

Files should generally stay under:

300 lines

Split large files.

---

# Naming Conventions

Variables → camelCase  
Components → PascalCase  
Files → kebab-case  
Database → snake_case

Example:

user-profile-card.tsx

---

# Code Organization

UI code → components  
Logic → lib/services  
Validation → lib/validations  

Avoid mixing responsibilities.

---

# Readability

Code must prioritize readability over cleverness.

Prefer clear naming.
